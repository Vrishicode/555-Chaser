# 555-Chaser
Basic description: This is a blinky board/ 555 led chaser which i made for forge in hack club and i changed it and made it so that it looks like a clock.
Why i built it: So i was looking for a project in the guides that was not too difficult so that i could get my hands dirty/ get used to how kicad works and building by first pcb. I just wanted to build this so i would understand how kicad works before moving onto harder/more complex projects and make things that are interesting and make things to build a portfolio.

Whats next: I used this to understand the basics of kicad before moving onto a harder guide/project which is the flight controller and after i will move on to making various controllers for video games like for a racing game, war thunder, etc.
